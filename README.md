# منظومة استمارات تقييم الأداء 2025-2026 — جامعة الموصل

منظومة إلكترونية لملء استمارات تقييم الأداء الوزارية، يدخلها التدريسي ببريده الرسمي لجامعة الموصل.

برمجة وتصميم: علي عبد الوهاب الصفار

## طريقة العمل

1. يسجّل التدريسي ببريده الرسمي (`@uomosul.edu.iq`) وكلمة مرور، ويؤكد حسابه من رسالة تصله على بريده.
2. يختار من مكتبة الاستمارات الاستمارة التي تخصه، ويملؤها ويرفع وثائقه. كل شيء يُحفظ في حسابه.
3. إن كان في الاستمارة محور يقيّمه المسؤول المباشر، يكتب التدريسي البريد الرسمي لمسؤوله مرة واحدة، فتصل إليه الاستمارة تلقائياً.
4. يدخل المسؤول بحسابه، فيرى استمارات التدريسيين الذين كتبوا بريده فقط، ويضع درجات محاوره.
5. تُدمج درجات المسؤول مع باقي المحاور، وتظهر الدرجة النهائية عند التدريسي.

## الملفات

- `index.html` — المنظومة كاملة.
- `config.js` — إعدادات مشروع Firebase (`uom-evaluation`).
- `firestore.rules` — قواعد حماية قاعدة البيانات.

## إعداد Firebase (مرة واحدة)

1. Authentication: تفعيل طريقة الدخول Email/Password.
2. Authentication > Settings > Authorized domains: إضافة `alialsaffarmosuluniversity.github.io`.
3. Firestore Database: إنشاء قاعدة البيانات.
4. Firestore Database > Rules: لصق محتوى الملف `firestore.rules` ثم Publish.

## حالة الاستمارات

- جاهزة: استمارة رقم (10).
- قيد الإعداد: باقي الاستمارات، وتظهر في المكتبة مع رابط نسختها الأصلية.
